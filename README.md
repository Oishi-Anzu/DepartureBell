# DepartureBell

**DepartureBell** は、鉄道車両の発車ベルや車内放送を再生・制御するためのWindows向けアプリケーションです。

音源の管理、再生方式の設定、シリアル通信による外部機器との連携などの機能を備えています。

## 主な機能

- 発車メロディの再生
- 戸閉放送の再生
- 音源ファイルの管理
- 音量調整
- 再生モードの切り替え
- シリアルポート（COM）の選択・接続
- 外部機器とのシリアル通信
- 設定の管理

### 再生モード

以下の再生モードに対応しています。

- 通常
- 立川式
- 西荻窪式
- 新幹線式

### 戸閉放送

停止時に戸閉放送を再生する機能を備えています。

戸閉放送の再生中に再生操作が行われた場合の動作も設定できます。

## 動作環境

- OS：Windows 10 / Windows 11
- アーキテクチャ：x64
- .NET：.NET 10 Desktop Runtime
- シリアル通信を利用する場合：対応するシリアルポートおよび外部機器

## インストール・起動方法

GitHubのReleasesから配布ファイルをダウンロードしてください。

1. 配布ファイルをダウンロードします。
2. ZIP形式の場合は任意の場所に展開します。
3. 必要な.NET Desktop Runtimeをインストールします。
4. `DepartureBell.exe` を実行します。

## 設定

アプリケーション内の設定画面から、音量、再生モード、戸閉放送、シリアル通信などの設定を行えます。
